# Track V 3면 CAD 복원 체크리스트

## V1a — 입력·계약

- [x] 정면(X×Z), 평면(X×Y), 우측면(Y×Z) 파일을 별도 필수 슬롯으로 받는다.
- [x] 제1각법/제3각법 선택을 분석 manifest에 저장한다.
- [x] 공통 가로 X, 깊이 Y, 높이 Z를 양수·10,000mm 이하로 검증한다.
- [x] 분석 이미지를 24시간 TTL 임시 저장소에서 안전한 analysis ID로 조회한다.
- [x] 사진성·과다 세부 입력은 3면 생성에서도 차단한다.
- [ ] 뷰별 회전·crop·기준점 축척을 제공한다.
- [ ] 공통 축 치수 불일치 위치를 표시한다.

## V2a — 직교 교집합 CAD

- [x] `DesignSpec 2.0`에 선언형 `orthographic_intersection` part가 있다.
- [x] 정면을 XZ, 평면을 XY, 우측면을 YZ 방향으로 돌출한다.
- [x] 세 솔리드의 교집합을 단일 CadQuery 솔리드로 만든다.
- [x] polygon·circle hole을 각 뷰의 절삭 실루엣으로 반영한다.
- [x] SQLite 설계 이력, Three.js Viewer, STEP/STL 다운로드에 연결한다.
- [x] 직육면체 회귀가 100×60×40mm와 240,000mm³를 재현한다.
- [x] L형 정면 회귀가 bounding box가 아닌 165,000mm³ L형 프리즘을 재현한다.
- [ ] 생성 솔리드의 정면·평면·우측면 재투영 IoU를 계산한다.
- [ ] 숨은선·중심선을 구멍·포켓·단계 피처로 변환한다.

## 실제 동작 검증

- [x] 백엔드 API에서 3개 이미지를 분석하고 각 정규화 이미지를 조회했다.
- [x] API가 120×80×60mm 유효 `orthographic_intersection`을 생성했다.
- [x] 생성된 STEP 다운로드가 HTTP 200을 반환했다.
- [x] 실제 Edge에서 탭 선택→3개 업로드→분석→생성→3D 결과를 관찰했다.
- [x] 브라우저 런타임 오류가 없었다.
- [ ] 실제 사용자 3면도+정답 STEP 10세트 검증은 입력 부재로 미완료다.
